## Output model

Every generation produces two things:

1. **The SVG artefact** — the actual crest or flag image, built programmatically from a heraldic component library. The AI picks the elements; code assembles the SVG.
2. **The Herald's Commentary** — text outside the SVG boundary, one block per element, written in the Herald's register (Dry Note / Herald's Aside / Modern Tariff as appropriate).

The visual artefact and the commentary are designed together but rendered separately. The commentary is not inside the image. It surrounds it.

---

## Data flow

```
User input (location or family/group name + Defence Lens)
        ↓
[AI Call 1 — Research]
  Worker /research route
  Tier 1: structured data (elevation, IMD, flood plain, constituency)
  Tier 2: LLM-parsed (local history, notable figures, industrial past)
  Tier 3: pure LLM (dark history, spurious heritage, buried misdemeanour)
  Returns: raw research findings JSON
        ↓
[AI Call 2 — Design]
  Worker /design route
  Input: research findings + selected Defence Lens
  Returns:
    - Heraldic spec JSON (field, division, charges, tinctures, motto, supporters)
    - Excuse (contextually derived from findings + lens)
    - Herald's Commentary (one block per element, in Herald's register)
        ↓
[SVG Renderer — client side]
  svg-renderer.js reads heraldic spec JSON
  Assembles SVG from component library
  Renders crest or flag in browser
        ↓
[Display]
  SVG image (the artefact)
  Herald's Commentary blocks surrounding it
```

Two AI calls means: swap the lens without re-researching. Tune the comedy register without touching the research layer.

## Heraldic vocabulary (controlled — AI picks from this list)

The AI does not invent heraldic terms. It selects from the vocabulary defined in `heraldic-vocabulary.js`. This is the anti-corruption layer — knowledge in files, not in training memory.

**Tinctures:**
- Metals: Or (gold), Argent (silver)
- Colours: Gules (red), Azure (blue), Sable (black), Vert (green), Purpure (purple)

**Field divisions:**
- Per pale, per fess, per bend, quarterly, gyronny, chequy, barry, paly

**Ordinaries (primary geometric charges):**
- Fess, pale, bend, chevron, cross, saltire, chief, pile, bordure

**Charges (figures):**
- Lion rampant, lion passant, eagle displayed, castle, tower, ship, sword, hand, crown, fleur-de-lis, serpent, bear, bull, key, hammer, wheel
- [Grows as product develops]

**Motto:** Latin or vernacular. Generated by AI — not from a fixed list. The motto is where the comedy lands most directly.

## Heraldic spec JSON (example)

```json
{
  "mode": "flag",
  "subject": "Slough",
  "lens": "context_is_everything",
  "field": {
    "tincture": "sable",
    "division": "per_pale",
    "secondary_tincture": "gules"
  },
  "charges": [
    { "id": "wheel", "tincture": "or", "position": "dexter" },
    { "id": "key", "tincture": "argent", "position": "sinister" }
  ],
  "motto": "Magis quam apparet",
  "motto_translation": "More than it appears",
  "excuse": "The area's development patterns reflect decisions made, in good faith, by people who have since relocated.",
  "commentary": [
    {
      "element": "field",
      "text": "The field — divided per pale Sable and Gules, colours associated historically with both industry and a certain categorical finality — was chosen to reflect the borough's long and, in many respects, ongoing relationship with outcomes."
    },
    {
      "element": "wheel_charge",
      "text": "The wheel, Or, commemorates the area's significant contribution to the transport infrastructure of the South East, a contribution that those who use the A4 daily continue to feel quite directly."
    },
    {
      "element": "key_charge",
      "text": "The key, Argent, represents access — specifically the question of it, which has, over several decades, generated a volume of correspondence with the local authority that historians describe as substantial."
    },
    {
      "element": "motto",
      "text": "The motto Magis quam apparet — More than it appears — was adopted in 1987. Records do not indicate what it was felt to be more than."
    }
  ]
}
```

## What is NOT in scope for first build

- Image generation API (DALL-E, Stability etc.) — SVG-first, image gen later
- User accounts or saved crests
- Sharing / export
- Mode 2 (family crest) — Mode 1 (location flag) ships first
- International locations — UK/Irish postcodes initially
